# Aoun — Next Feature Ideas

This document suggests product features that fit the current Aoun surface area instead of restarting the product direction. The site already has:

- public browsing by university → major → course
- resource catalog + news per major
- anonymous local progress tracking
- GPA calculator
- push notifications
- admin/contributor dashboard with Convex-backed CRUD

The best next features are the ones that deepen student usefulness and improve content quality without requiring a full account system.

## Highest-Leverage Features

### 1. Exam and Deadline Calendar

Create a major-level calendar for:

- exam dates
- registration deadlines
- add/drop deadlines
- project deadlines
- contributor-posted key dates

Why this fits:

- Pairs well with news and notifications.
- Gives students a reason to subscribe beyond passive browsing.

### 2. Missing Resource Requests

Add a lightweight request flow on course pages:

- "اطلب مصدر لهذه المادة"
- optional category selection: summaries, exams, videos, etc.
- show open request count on course pages
- contributors see requests in dashboard for their majors
- allow marking requests as fulfilled when a matching resource is added

Why this fits:

- The biggest content problem is usually coverage gaps, not discovery alone.
- It gives students a voice without opening full comments/moderation complexity.
- It gives contributors a clear queue of what to add next.
